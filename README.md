# Prostuti – Quiz App v2

Interactive Quiz Application with Category, History & Chart Visualization

Prostuti Quiz App v2 is a responsive and interactive quiz application built using HTML, CSS, Vanilla JavaScript, JSON, Chart.js, and localStorage.

This project is an upgraded version of Prostuti Quiz App v1, featuring subject and difficulty selection, quiz history tracking, score visualization, subject-wise performance analysis, and mistake review functionality.

Users can practice multiple-choice questions, track their learning progress, and improve their performance by reviewing incorrect answers.



# Quiz Features

Select a subject before starting a quiz.

Choose difficulty: Easy, Medium, or Hard.

3 subjects: HTML, CSS, and JavaScript.

90 multiple-choice questions stored in JSON.

10 questions per normal quiz.

Random question and option shuffling.

20-second countdown timer for each question.

Automatic question navigation when time expires.

Dynamic progress bar.

Automatic score calculation.

Detailed answer review with correct and incorrect answers.

High-score tracking using localStorage.


# Quiz History & Analytics

Save completed quiz results in localStorage.

Store quiz date, subject, difficulty, and score.

Display previous attempts in a history table.

Show total completed quizzes.

Display best score and overall average score.

Visualize score trends using Chart.js.

Calculate average scores for individual subjects.

Clear quiz history with confirmation.



# Mistake Review Mode

Automatically save incorrectly answered questions.

Display the total number of mistakes.

Show subject-wise mistake counts.

Practice previously incorrect questions.

Remove questions from the mistake list after answering correctly.

Keep mistake practice results separate from normal quiz history.
